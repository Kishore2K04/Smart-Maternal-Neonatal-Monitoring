# Smart Maternal & Neonatal Health Monitoring System

An IoT-inspired real-time monitoring prototype designed to demonstrate continuous maternal and neonatal health monitoring, threshold-based risk detection, cloud synchronization, and emergency alert notifications.

## 🚨 Project Overview

The system simulates a connected maternal and neonatal health monitoring environment.

Patient monitoring data is continuously generated by a simulated IoT sensor layer and sent to Firebase Realtime Database. A rule-based risk engine evaluates the readings against predefined thresholds.

When an abnormal condition is detected:

- The corresponding vital is highlighted on the live dashboard.
- The detected risk is displayed immediately.
- A Telegram alert is sent to the configured recipient.
- Monitoring continues with the next reading.

The prototype was developed to demonstrate the complete IoT-to-cloud-to-alert workflow when physical medical sensors were not available during development.

---

## 🎯 Problem

Maternal and neonatal health conditions can require continuous monitoring of important physiological parameters.

In resource-constrained environments, delayed recognition of abnormal readings can make timely intervention difficult.

This prototype explores a low-cost connected monitoring architecture where sensor readings can be continuously transmitted to a centralized system and abnormal conditions can trigger immediate notifications.

---

📊 Monitored Parameters

The prototype monitors:

Parameter	Example Threshold
Blood Pressure	Systolic > 140 or Diastolic > 90
SpO₂	< 94%
Urine Protein	+ or ++
Bilirubin	> 12 mg/dL

These thresholds are used only for demonstrating the prototype's rule-based alerting mechanism and should not be interpreted as clinical diagnostic criteria.

⚙️ Installation
1. Clone the repository
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd Smart-Maternal-Neonatal-Monitoring
2. Create a virtual environment
python -m venv .venv
3. Activate the environment

Windows:

.venv\Scripts\activate
4. Install dependencies
pip install -r requirements.txt
🔐 Configuration

Create a .env file based on .env.example.

TELEGRAM_BOT_TOKEN=your_telegram_bot_token
TELEGRAM_CHAT_ID=your_telegram_chat_id

Place your Firebase Admin SDK credentials in:

firebase_key.json
Security

The following files contain sensitive information and must never be committed:

.env
firebase_key.json

They are excluded through .gitignore.

⚠️ Prototype Limitations

This project is a prototype.

Physical medical sensors were not available during the original development, so physiological readings are simulated.

The system demonstrates:

IoT data flow
Cloud synchronization
Threshold-based risk detection
Real-time visualization
Automated alerting

It is not a medical device and does not provide clinical diagnosis or medical advice.
